# Abyss Light (abyss-light) README

Abyss Light is a light-weight palette inspired by VS Code's Abyss theme.  
Keywords such as `def` and `end` intentionally blend into the background so
that function names and calls remain the primary visual anchors when reading
code.

## How to make a custom theme

* [Build your own VS Code Theme](https://learn.microsoft.com/en-us/shows/vs-code-livestreams/build-your-own-vs-code-theme) — A video tutorial that helped me get started.
